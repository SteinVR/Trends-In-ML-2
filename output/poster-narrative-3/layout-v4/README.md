# Legal RAG — layout v4

- `poster.pdf` — постер, один лист DIN A1, альбомная ориентация (841 × 594 мм).
- `index.html` — редактируемый исходник, открывается в браузере и подстраивается под ширину окна.
- `preview.png` — превью для просмотра. Для печати используйте PDF.
- `export.mjs` — повторная сборка PDF и превью из HTML.

Композиция и оформление основаны на `external/Layout-v4.jpg`. Текст всех 13 блоков и полная библиография взяты из `external/Final layout and text.pdf`. Служебные указания вроде «Keep graphs from previous design» не печатаются. Заголовок постера, университетский логотип и обязательная ссылка на код сохранены из предыдущего постера. Подзаголовок, подпись кафедры, Interpretation и Model rationale из картинки не добавлены.

Три колонки адаптированы под полный текст и A1. Основные абзацы — 24 pt, исследовательский вопрос — 25 pt, библиография — 18 pt. Шрифты Barlow Condensed и Noto Sans приложены с лицензиями. Графики и схема в PDF векторные. Значения трёх графиков и OCR-контроля сохранены из `../results/metrics.csv`; сгенерированные числа на JPG не использованы.

Пересборка из этой папки, с установленными Node.js, Playwright и Chromium:

```sh
NODE_PATH=<directory-containing-playwright> node export.mjs
```

По умолчанию используется `/usr/bin/chromium`; другой путь задаётся через `CHROMIUM_PATH`. Экспорт проверяет границы колонок, наличие изображений и минимальный размер абзацев. Диагностика записывается в `tmp/layout-v4/` в корне проекта. Старые варианты постера не перезаписываются.
