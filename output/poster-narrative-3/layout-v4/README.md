# Legal RAG — layout v4

- `poster.pdf` — постер, один лист DIN A1, альбомная ориентация (841 × 594 мм).
- `index.html` — редактируемый исходник, открывается в браузере и подстраивается под ширину окна.
- `preview.png` — превью для просмотра. Для печати используйте PDF.
- `export.mjs` — повторная сборка PDF и превью из HTML.

Композиция и оформление основаны на `external/Layout-v4.jpg`. Текст всех 13 блоков и полная библиография взяты из `external/Final layout and text.pdf`. Служебные указания вроде «Keep graphs from previous design» не печатаются. Заголовок постера, университетский логотип и обязательная ссылка на код сохранены из предыдущего постера. Подзаголовок, подпись кафедры, Interpretation и Model rationale из картинки не добавлены.

Три колонки адаптированы под полный текст и A1. Порядок чтения: 1–5 слева, 6–8 в центре, 9–13 справа. Блок 8 следует за оценочными метриками; ширина графиков увеличена примерно на 38% относительно первого варианта layout-v4.

Композиция схемы приближена к `../powerpoint/preview.png`: базовая цепочка с R0 слева, embedding-модель непосредственно под Semantic retrieval, описание генератора с его моделью, общий ряд иконок и нижние цветные полосы с техническими подписями. Иконка R6 заменена на документ с цепочкой. У R2 короткий заголовок «Multiple scales», а полная исходная формулировка «Represent evidence at multiple scales» сохранена в описании; перечень масштабов находится в нижней полосе. Исследовательские абзацы, числа и библиография сохранены.

Под названием расположены имена Aleksandr Loginov и Yulia Malakhova. Заголовок — 42 pt, имена — 24 pt; логотип остаётся справа. Блоки 8–10 объединены префиксом Results: Pipeline performance, OCR robustness и Hypothesis evaluation.

Основные абзацы — 24 pt, исследовательский вопрос — 25 pt, библиография — 16 pt. Шрифты Barlow Condensed и Noto Sans приложены с лицензиями. Графики и схема в PDF векторные. Значения трёх графиков и OCR-контроля сохранены из `../results/metrics.csv`; сгенерированные числа на JPG не использованы.

Пересборка из этой папки, с установленными Node.js, Playwright и Chromium:

```sh
NODE_PATH=<directory-containing-playwright> node export.mjs
```

По умолчанию используется `/usr/bin/chromium`; другой путь задаётся через `CHROMIUM_PATH`. Экспорт проверяет границы колонок, наличие изображений, минимальный размер абзацев, выравнивание строк схемы и порядок блоков правой колонки. Диагностика записывается в `tmp/layout-v4/` в корне проекта. Старые варианты постера не перезаписываются.
