# PowerPoint — Layout v4

`legal-rag-layout-v4.pptx` — один редактируемый слайд формата A1, 841 × 594 мм, с утверждённой компоновкой `../index.html` и `../poster.pdf`.

Перед открытием установите четыре файла `.ttf` из папки `fonts`, затем перезапустите PowerPoint. Шрифты приложены отдельно и не встроены в PPTX. Без них приложение может заменить гарнитуру и изменить вид текста.

Текст, фоны, карточки, линии и точки графиков — редактируемые элементы PowerPoint. Блоки сгруппированы: для изменения внутренних элементов раскройте группу или разгруппируйте её. Текст разбит по исходным строкам для сохранения переносов. Графики состоят из векторных фигур и подписей, а не объектов диаграмм Excel; изменение чисел не перестраивает линии автоматически. Иконки и логотип сохранены в формате SVG.

`preview.png` — рендер именно этой презентации. Проверено открытие и экспорт в LibreOffice, формат A1, все 289 текстовых фрагментов, геометрия и целостность PPTX. Схема и весь постер сравнены с утверждённым макетом. Отображение в Microsoft PowerPoint на этой машине не проверялось.

`legal-rag-layout-v4-with-fonts.zip` содержит презентацию, шрифты с лицензиями, превью и эту инструкцию. Исходный HTML/PDF не изменён.
